Websites

Here is a collection of links to interesting, fun or useful websites.

  • Bible Read the Bible online.
  • w3schools There is a lot of information about programming on this website. Parts of the code of this website come from here, and w3schools was consulted regularly during the making of this website.
  • Overleaf online text-editor, better suited for professional publications than Microsoft Word.
  • Indipendent Media Initiative An initiative that rewards high quality content creators.
  • Open Street Map Public digital map.
  • Internet Archive A digital public library that collects and stores digital information.
  • Project Gutenberg A digital public library for e-books.

Software

  1. Blender Open-source 3D software modelling and animation.
  2. FreeTube Een app die het mogelijk maakt om anoniem en reclamevrij YouTube te kijken.

Games

A list of games that I like to play or have played in the past.

  1. OpenTTD An open-source version of the classic game Transport Tycoon Deluxe.
  2. OpenRCT2 An open-source version of the classic game Rollercoaster Tycoon.
  3. Microsoft Flight Simulator Currently the best looking flight simulator on the market.
  4. Euro Truck Simulator 2 Great relaxing simulator.
  5. Minecraft The classic block game.
  6. Lego Worlds Een Lego game that is similar to minecraft. I used to play this a lot.
  7. Slay A turn-based strategy game. Simple and old, but quite fun.
